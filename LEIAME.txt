CONTROLE DE PROCESSOS

VERSAO ONLINE (pasta docs/)  - site estatico + Supabase (Postgres, login e RLS)
  Publicacao: GitHub > Settings > Pages > Deploy from a branch > main, pasta /docs.
  Logins de demonstracao: ver o responsavel pelo projeto (nao ficam no repositorio).
  Contas novas: criar em Supabase > Authentication > Users; aparecem em "Usuarios" aguardando liberacao.
  Exportar Excel: botao no Painel (Resumo Executivo com graficos, Processos, Por Cliente com curva ABC, Historico).

VERSAO LOCAL (server.js)  - Node.js 22.5+ com SQLite, sem npm install
  Rodar: duplo clique em iniciar.bat  ->  http://127.0.0.1:8080  (admin / admin123, operador / operador123)
  Sem acesso de administrador? Use o Node portatil (zip) em %LOCALAPPDATA%\node-portatil.
